1 · What the mailer is

The Conference Mailer sends personalized email invitations to the conference contact list, one separate email per person, from the conference Gmail account (info@westernpagis.com). From this page you find and edit contacts, send a mailing, and check what went out. No spreadsheet or mail merge is needed.

Behind the page sits the Google Sheet WPA GIS Conference Contacts, owned by the conference account. It is the master copy; you never have to open it for everyday work (Open sheet at the top opens it if you need to).

2 · Connect the page (once per browser)
  1. Click Connection at the top, if the Connection box isn't already open.
  2. Type the access key (the conference chair gives it to committee members).
  3. Tick Remember the key in this browser on your own computer, then click Connect. The contacts load after a few seconds.

On a shared computer leave Remember unticked; the key is forgotten when you close the tab. Forget saved key removes it at any time. The web app address is built into the page; use Change web app address only if the script is ever redeployed under a new address (leave the field blank to return to the built-in one).

The access key gives full access to every contact. Keep it within the committee.

3 · Find & fix contacts
  1. On Contacts, type a name, email or organization in Search, or narrow the list with Status, List / tag, Role and Last took part.
  2. Click a row to open it, change what you need, and click Save.
  3. To add someone, click + Add contact. Only the email is required.

To change many people at once, tick their rows and use Add tag, Remove tag or Set status in the bar that appears. Export shown (CSV) downloads exactly the rows on screen.

StatusGets email?Set by
ActiveYesDefault for every contact
UnsubscribedNoThe person clicked "unsubscribe"
BouncedNoThe address came back undeliverable
InvalidNoThe address is malformed or known to be dead

Never set someone back to Active after they unsubscribed unless they ask you to.

4 · Send a mailing
  1. Write the email as a draft in the conference Gmail account. Logos, formatting and attachments carry over. Personalize with {{FirstName}} or {{FirstName|Colleague}} (the word after the bar is used when the name is blank); {{Affiliation}} and any other column name work too, in the subject as well.
  2. On Settings & tools, click Process unsubscribes & bounces so last mailing's opt-outs are skipped.
  3. On Compose & send, pick the draft and tick the lists or tags to send to (or all active contacts). The recipient count and today's quota appear.
  4. Click Send me a test and check it in your inbox.
  5. Type a Campaign name (e.g. 2027 Call for Presentations), click Start sending, and click again to confirm.

Emails go out in batches about a minute apart, and you can close the page. The conference account gets a summary email at the end. Stop sending pauses; starting the same campaign name again resumes and never emails anyone twice. Keep the Gmail draft until the summary arrives. Google allows about 1,500 emails a day; a larger mailing finishes the next day by itself.

5 · Check the send log

On Send log, filter by campaign, result or email to see who got a mailing and when. The totals show sent and failed counts per campaign. Reload log fetches the latest entries.

6 · Import a list someone shared
  1. On Import a list, choose the CSV or Excel file and type where it came from in Source of this list (e.g. CCAP members 2027). That name is also added as a tag.
  2. Check the column matches. Outlook and Access headings are recognized; change any drop-down that is wrong.
  3. Click Check against the contact list and review the groups: New contacts (added as Active), Already in the list (only blank fields are filled), Possible duplicates (same name, different email: choose Skip, Same person or Different person) and Skipped (no or invalid email, old Clarion addresses).
  4. Click Import. Existing contacts never change status.
7 · Habits & quick fixes
  • Run Process unsubscribes & bounces before every mailing, and always send yourself a test first.
  • Use a new campaign name for a mailing everyone should get again; reuse a name only to reach people added since.
  • Don't delete or send the Gmail draft while a campaign is running.
  • Don't add old @eagle.clarion.edu or @clarion.edu addresses; they no longer work.

8 · For the maintainer

The tool has four parts: Code.gs (sending engine), Api.gs (web API that checks the key) and Sidebar.html (in-sheet panel) live in the sheet's Apps Script project; this page is conference-mailer.html. After any script change: Deploy → Manage deployments → Edit → Version: New version → Deploy, which keeps the same address. To change the key: sheet menu Conference Mailer → Set web page access key…. Full setup steps, the column reference and the code are in the full user guide (claude.ai doc "Conference Mailer – Committee User Guide", and the Word/PDF copy in the GISDay\ConferenceManagement\ConferenceMailer folder).
